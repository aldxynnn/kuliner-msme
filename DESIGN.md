
# UI/UX DESIGN SYSTEM

## Overall Design Direction

Create a polished, modern commercial product.

The visual identity must feel like a real culinary
technology product, not a generic AI-generated template.

The customer website and Android application must
share a consistent brand identity.

## Brand Personality

- Modern.
- Warm.
- Clean.
- Friendly.
- Professional.
- Trustworthy.
- Easy to use.

## Color Palette

Use a warm culinary-inspired palette.

- Primary: Terracotta / Deep Orange.
- Background: Warm Cream / Off White.
- Surface: White.
- Main Text: Dark Charcoal.
- Secondary Text: Muted Gray.
- Success: Green.
- Warning: Amber.
- Error: Red.

Use colors consistently.
Avoid introducing random colors.

## Typography

Preferred:
- Plus Jakarta Sans.
- Inter.

Use a clear typography hierarchy.
Keep body text readable.
Avoid oversized headings.

## Components

Use consistent:
- Buttons.
- Input fields.
- Dropdowns.
- Navigation.
- Cards.
- Dialogs.
- Tables.
- Status badges.
- Product cards.
- Empty states.
- Loading indicators.
- Toast notifications.

Use Lucide icons on the website.
Use appropriate Material icons on Android.

## Customer Website Design

The website must be mobile-first.

Visual direction:
- Premium modern food ordering experience.
- Beautiful food photography.
- Clean menu browsing.
- Clear category navigation.
- Attractive product cards.
- Easy-to-use cart.
- Simple checkout.
- Visible order status.

Avoid:
- Overcrowded layouts.
- Excessive decorations.
- Unnecessary animations.
- Too many colors.
- Generic landing page sections unrelated to ordering.

## Android POS Design

Use native Jetpack Compose and Material 3.

Visual direction:
- Professional restaurant POS.
- Clean dashboard.
- Efficient navigation.
- Clear order lists.
- Readable transaction information.
- Easy payment confirmation.
- Consistent order status indicators.
- Practical forms.

Optimize for real cashier workflows.

## Layout Rules

- Consistent spacing based on 4px or 8px.
- Consistent border radius.
- Balanced whitespace.
- Clear alignment.
- Strong visual hierarchy.
- Responsive layouts.
- Accessible contrast.
- Comfortable touch targets.

## Anti-AI-Slop Rules

NEVER:
- Generate generic dashboard templates.
- Use excessive glassmorphism.
- Use unnecessary gradients.
- Put every element inside a card.
- Use random illustrations.
- Use emoji as icons.
- Use inconsistent spacing.
- Use fake charts or fake statistics.
- Add decorative sections without purpose.
- Use placeholder content in final UI.

Use realistic Indonesian product names,
prices, descriptions and food imagery.

## Quality Standard

Every screen must look intentionally designed.

The interface must be visually consistent,
functional, responsive, and suitable for real users.

Prioritize usability and clarity over decoration.
