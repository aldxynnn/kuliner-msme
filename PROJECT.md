
# PROJECT OVERVIEW

## Product Name
Kuliner MSME Management System

## Project Description

An integrated ordering and business management system
designed for small and medium-sized culinary businesses.

The system consists of:
1. Customer ordering website.
2. Android cashier and admin application.
3. Central backend and database.

Both applications must use the same backend and database.

## Technology Stack

### Customer Website
- React
- Vite
- TypeScript
- Tailwind CSS
- shadcn/ui
- Lucide Icons

### Android Application
- Native Android
- Kotlin
- Jetpack Compose
- Material 3
- Retrofit
- Navigation Compose
- Kotlin Coroutines

### Backend
- Node.js
- NestJS
- TypeScript
- REST API
- Prisma ORM

### Database
- PostgreSQL

### Architecture
- Client-server architecture.
- REST API communication.
- Centralized database.
- Environment-based configuration.

## Main Objectives

- Make food ordering easier through table QR codes.
- Help cashiers manage orders and payments.
- Help business owners manage products and categories.
- Provide simple financial reports.
- Connect customer ordering and cashier operations
  in one integrated system.

## Language and Localization

- Interface language: Indonesian.
- Currency: Indonesian Rupiah (Rp).
- Timezone: Asia/Jakarta.
- Date format: Indonesian-friendly.
- Use realistic Indonesian culinary business data.

## Development Scope

Build a functional MVP suitable for a university
Mobile Device Programming project.

Prioritize core features and reliable integration.

Do not implement unnecessary enterprise features.
